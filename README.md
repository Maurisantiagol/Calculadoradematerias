# Calculadoradematerias

App Android (Java) para calcular promedios de materias. Es un proyecto escolar de 2022 (entregable final) y está abandonado.

## Qué hace

- Calcula el promedio de las calificaciones de una materia, desde una sola pantalla (`MainActivity.java`, paquete `com.example.calculadorapromediossdlm`).

## Stack

- Java
- Android con Gradle (`build.gradle`, `gradlew`)

## Cómo correrlo

1. Abre el proyecto en Android Studio.
2. Sincroniza Gradle.
3. Ejecuta la app en un emulador o dispositivo Android.
